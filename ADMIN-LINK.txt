## 1) Abhi, is sandbox ka live preview (server chal raha hai)
   Live preview link (port 3000) ke aage yeh path lagao:

       /ngd-control-8421/

   Jaise:  https://3000-xxxxxxxx.e2b.app/ngd-control-8421/

   Sign in with the credentials configured in .env.local. If credentials are not configured,
   the page explains how to enable sign-in and the admin API remains locked.

## 2) Apne computer par (npm run dev ke baad)
       http://localhost:3000/ngd-control-8421/

## 3) Vercel par deploy hone ke baad
   Agar ADMIN_PATH env set hai  →  https://tumhari-site.vercel.app/ngd-control-8421/
   Agar ADMIN_PATH set nahi hai →  https://tumhari-site.vercel.app/admin
   Admin sign-in is required. Configure TEAM_MEMBERS or ADMIN_PASSWORD in Vercel settings.

   ZAROORI: yeh link kahin public mat likho. Bookmark kar lo.
   Path badalna ho to Vercel → Settings → Environment Variables → ADMIN_PATH,
   ya locally .env.local mein ADMIN_PATH ki value badal do.

## Not working? yeh check karo
   * /admin (bina path) jaan-boojh kar 404 deta hai — sirf /ngd-control-8241/ chalega.
   * 308 aaye to trailing slash ke saath URL kholo — /ngd-control-8241/
   * Login screen aaye to .env.local credentials use karo. If sign-in is not configured, add
     ADMIN_PASSWORD or TEAM_MEMBERS to the server environment before continuing.
   * "API not reachable" toast aaye to server band hai → npm run dev chalao.
