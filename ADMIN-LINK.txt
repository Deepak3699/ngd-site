NGD ADMIN DASHBOARD
===================

Default local path:
  http://localhost:3000/ngd-control-8421

Production:
  https://YOUR-DOMAIN/ngd-control-8421

For security, set ADMIN_PATH to your own long random path in the hosting
provider's environment settings. The dashboard then moves to:
  https://YOUR-DOMAIN/YOUR-ADMIN-PATH

Login is disabled until ADMIN_PASSWORD or TEAM_MEMBERS is configured.
A hidden path does not replace a strong password.

/admin intentionally returns 404.
The trailing-slash dashboard URL may normalize to the no-slash URL; both resolve.
Do not link the dashboard from public pages or share its URL publicly.

See README.md and .env.example for TEAM_MEMBERS, roles and alert settings.
