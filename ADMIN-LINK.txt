   (login dono jagah lagega — TEAM_MEMBERS ya ADMIN_PASSWORD set hone par)

   ZAROORI: yeh link kahin public mat likho. Bookmark kar lo.
   Path badalna ho to Vercel → Settings → Environment Variables → ADMIN_PATH,
   ya locally .env.local mein ADMIN_PATH ki value badal do.

## Not working? yeh check karo

   * 308 aaye to trailing slash ke saath URL kholo — /ngd-control-8241/
   * Login screen aaye to .env.local ke credentials use karo (upar diye hain).
   * "API not reachable" toast aaye to server band hai → npm run dev chalao.
